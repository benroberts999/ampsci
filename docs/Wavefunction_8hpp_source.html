27/*!
28 @brief Stores Wavefunction (set of valence orbitals, grid, HF etc.)
29
30 @details
31 Also holds the Hartree-Fock potential (and core), basis, spectrum,
32 correlation potential (Sigma), and CI solutions.
33
34 \par Construction:
35 - Set of GridParameters [see Maths/Grid]
36 - Nuclear::Nucleus [see Potentials/NuclearPotentials]
37 - var_alpha = \f$\lambda\f$, \f$\alpha = \lambda\alpha_0\f$
38 - run_label: Optional label for output identity - for distinguishing
39 outputs with different parameters
40
41 \par Copying:
42 A copy has its own HF object (and core), but its Sigma (if formed) still
43 refers to the HF object of the original (see copySigma). Applying Sigma
44 does not use the HF object, but forming or writing Sigma does: these then
45 use the original core (e.g., without any changes to the copy's HF), and the
46 original must outlive the copy.
47*/

59 @param grid Radial grid (shared resource)
60 @param nucleus Nuclear parameters (isotope, charge distribution)
61 @param var_alpha Ratio alpha/alpha_0
62 @param run_label Optional label for output identity (see identity)

64 Wavefunction(std::shared_ptr<const Grid> grid,

391 /*!
392 @brief Solves for exotic atoms (e.g., muonic), including screening.
393
394 @details
395 Resulting states are included in valence (flagged as exotic); the
396 screening also updates core.
397
398 Each state is first solved in the nuclear (+QED) potential. With
399 @p screening (and a non-empty core), the core HF equations are iterated
400 including the direct potential of the first exotic state; the HF object
401 (core) is then replaced by the screened one (Vnuc itself unchanged), and
402 the exotic states are re-solved in the screened potential.
403
404 Note: The exotic states are just added to the valence list, so they can
405 be used more simply with all the modules. However, be careful; for
406 example, RPA will now be meaningless for these states!
407
408 @param in_exotic_str States, in basis-string format (e.g., "1s2p")
409 @param mass Mass of the exotic particle, in units of m_e
410 @param screening Include screening (core and exotic states)
411 @param print Print energies and screening iterations
412
413 @note With @p screening, any (electron) valence states already present
414 are not re-solved, so are no longer consistent with the screened
415 core.
416 */
417 void solve_exotic(const std::string &in_exotic_str,
418 double mass = PhysConst::m_muon, bool screening = true,
419 bool print = true);

434 @brief First, fits Sigma to energies, then forms fitted Brueckner orbitals.
