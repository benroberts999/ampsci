21/*!
22 @brief Structure Radiation and Normalisation of states, using diagram method.
23
24 @details
25 Two main functions: SR(), norm(), which return the reduced matrix elements
26 for structure radiation and normalisation, respectively.
27
28 Structure radiation is sum of srTB()+srC(); norm() gives normalisation of
29 states.
30
31 * Typically, one should use splines for the 'legs' (outer states) of
32 diagrams. However, code is written such that {w,v} (the valence states)
33 always appear as the _first_ state in the Q integrals; thus those states
34 are always directly integrated (other states may use the existing y^k
35 integrals, which were calculated using the spline states), unless using
36 QkTable (see below).
37
38 * For using spline states as legs: This means you must typically ensure
39 basis is large enough to make relevant valence states "physical"
40
41 * The user should check if the zeroth order <w|t|v> matches closely between
42 valence/spline states. If not, basis/cavity is too small and SR+N probably
43 meaningless
44
45 * Option to use QkTable to calculate SR+N. Otherwise, calculates Coulomb
46 integrals on-the-fly. If QkTable is used, leads to ~10x speed-up, but uses
47 large amount of memory. Also, using QkTable means spline states are used
48 for "legs" of diagrams.
49
50 * norm() works differently: it directly takes in the operator to calculate
51 norm. This is because norm depends only on Coulomb operators.
52 In some sense, would make sense to keep norm in a separate class.
53 However, they are typically calculated together, and use the same Coulomb
54 integrals.
55
56 * Formulas are presented in (for example):
57 * W. R. Johnson, Z. W. Liu, and J. Sapirstein, At. Data Nucl. Data Tables
58 64, 279 (1996),
59 https://www.sciencedirect.com/science/article/pii/S0092640X96900248
60
61 * Specific form of formulas used here are presented in:
62 [Phys. Rev. A **107**, 052812 (2023)](https://arxiv.org/abs/2211.11134)
63
64 @note For Structure Radiation, must call StructureRad::solve_core() first.
65*/

69 /*!
70 @brief Construct a Structure Radiation (MBPT) object.
71
72 @details
73 en_core defines the core boundary: states with e < en_core are treated as
74 core states, while states with e > en_core are treated as excited states.
75 Typically en_core is half-way between max(e_core) and min(e_valence),
76 i.e., wf.FermiLevel().
77
78 nminmax is the pair {nmin, nmax}. Only core states with n >= nmin are used,
79 and only excited states with n <= nmax are included in the summations.
80 Negative-energy states (if in the basis) are always included as excited
81 states.
82
83 Qk_fname is the filename for the QkTable. If provided, the QkTable will be
84 read from / written to this file and then used to calculate SR. This leads
85 to ~10x speedup in the calculation at the cost of significantly higher
86 memory usage.
87
88 fk and etak are effective screening factors for screening and hole-particle.
89 These should only be used as a test.
90
91 @param basis Basis orbitals (typically splines); split into core and
92 excited states by @p en_core
93 @param en_core Core/excited energy boundary
94 @param nminmax {nmin, nmax}: n range of core/excited states included
95 @param Qk_fname QkTable file; if empty, no QkTable (Yk table used)
96 @param k_cut Maximum multipolarity k of the Coulomb integrals (see note)
97 @param fk Effective screening factors, for each k (test only)
98 @param etak Effective hole-particle factors, for each k (test only)
99 @param verbose If true, prints progress to screen
100
101 @note @p k_cut applies to every Coulomb line, including those inside
102 the exchange integrals (all Q^k, P^k, W^k with k > k_cut are zero),
103 whether or not a QkTable is used.
104 */

171 /*!
172 @brief Reduced matrix element of structure radiation, <w||h_sr||v>.
173
174 @details
175 Sum of the top, bottom, and centre diagrams, for the operator (and dV)
176 given to solve_core().
177
178 @param w Bra state
179 @param v Ket state
180 @param omega Operator frequency; enters the energy denominators of the
181 top and bottom diagrams
182
183 @note Must call solve_core() first; aborts otherwise.
184 @warning Returns zero if <w||h||v> is not in the solve_core() table: i.e.,
185 if zero by selection rules, or if @p w or @p v (matched by n and
186 kappa) is not in the basis.
187 */
188 double SR(const DiracSpinor &w, const DiracSpinor &v,
189 double omega = 0.0) const {
190 return srTB(w, v, omega) + srC(w, v);

220 /*!
221 @brief Returns sum of SR+Norm diagrams, reduced ME: <w||T+B+C+N||v>.
222
223 @details
224 SR() + norm().
225
226 @param w Bra state
227 @param v Ket state
228 @param h Operator, for norm() only (must not be null)
229 @param dV Core polarisation (RPA), for norm() only; may be null
230 @param omega Operator frequency: for the SR() denominators, and the sign
231 selects the dV component in norm()
232
233 @note Must call solve_core() first (aborts otherwise). h and dV used for
234 norm() only
235 */
236 double srn(const DiracSpinor &w, const DiracSpinor &v,
237 const DiracOperator::TensorOperator *const h,
238 const ExternalField::CorePolarisation *const dV = nullptr,
239 double omega = 0.0) const {
240 const auto tb = srTB(w, v, omega);
241 const auto c = srC(w, v);
242 const auto n = norm(w, v, h, dV, omega < 0.0);
243 return tb + c + n;
244 }

258 /*!
259 @brief Returns Brueckner orbital contribution to the reduced ME.
260
261 @details
262 From 10.1006/adnd.1996.0024:
263 \f[
264 f_v \redmatel{w}{h}{\delta v} + f_w \redmatel{\delta w}{h}{v},
265 \qquad
266 \ket{\delta v} = \sum_{i \neq v}
267 \frac{\ket{i}\matel{i}{\Sigma}{v}}{\varepsilon_v - \varepsilon_i},
268 \f]
269 where \f$ \Sigma \f$ is the second-order correlation potential at energy
270 \f$ \varepsilon_v \f$ (with fk and etak, if given), and the sum runs over
271 core and excited basis states with \f$ \kappa_i = \kappa_v \f$. The
272 \f$ \redmatel{w}{h}{i} \f$ are taken from the solve_core() table (so
273 include dV, if given there).
274
275 @param w Bra state
276 @param v Ket state
277 @param fw Factor multiplying the \f$ \redmatel{\delta w}{h}{v} \f$ term
278 @param fv Factor multiplying the \f$ \redmatel{w}{h}{\delta v} \f$ term
279
280 @note Must call solve_core() first; aborts otherwise.
281 @warning Terms are zero if @p w or @p v (matched by n and kappa) is not
282 in the basis.
283 */
284 double BO(const DiracSpinor &w, const DiracSpinor &v, double fw = 1.0,
285 double fv = 1.0) const;
