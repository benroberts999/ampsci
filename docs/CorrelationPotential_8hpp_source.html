33/*!
34 @brief Fits the coefficient a_eff of the large-r polarisation tail of Sigma.
35
36 @details
37 Large-r tail: \f$ \Sigma(r) \to a_{\rm eff}/r^4 \f$.
38
39 Averages \f$ r^4 (\Sigma F_v)(r)/F_v(r) \f$ (large component) over @p n_fit
40 sub-grid points: the outermost ones where
41 \f$ |F_v| \geq f_{\rm cut} \max|F_v| \f$ (stopping at a node). Further out,
42 Fv is exponentially small and the ratio is dominated by numerical noise in
43 Sigma. In the fit region (outside the core, typically a few to ~15 aB)
44 \f$ r^4 (\Sigma F_v)/F_v \f$ is already close to constant.
45
46 @return a_eff; zero if there are no points in the fit region.
47
48 @note Can be numerically unstable, should be treated as a test
49*/
50double fit_tail_coefficient(const GMatrix &Sigma, const DiracSpinor &Fv,
51 std::size_t n_fit = 10, double f_cut = 1.0e-2);
52
53/*!
54 @brief Adds the large-r polarisation tail of Sigma to @p SigmaFn.
55
56 @details
57 Adds \f$ (a_{\rm eff}/r^4) F_n \f$ for r beyond the Sigma sub-grid (where
58 \f$ \Sigma F_n \f$ is zero). Treated as a local potential. Acts on the small
59 component only if @p Sigma includes g parts. Does nothing if @p a_eff is
60 zero.
61*/
62void add_tail(DiracSpinor *SigmaFn, const GMatrix &Sigma, const DiracSpinor &Fn,
63 double a_eff);

83/*!
84 @brief Correlation potential, Sigma, for valence states.
85
86 @details
87 Core-valence correlations, stored as a non-local matrix for each kappa, on
88 a radial sub-grid (every stride-th point of the full grid, between r0 and
89 rmax). Formed at a given energy (see formSigma). Read from file if it
90 exists, so it need only be formed once (see write).
91
92 Direct diagrams are formed using either the Goldstone (basis sum) or Feynman
93 (Green's function) technique; the Feynman technique allows all-order
94 inclusion of screening and the hole-particle interaction. Exchange diagrams
95 always use Goldstone, with optional effective screening factors fk.
96
97 The action of Sigma on a state (SigmaFv) includes:
98 - lambda scaling, \f$ \Sigma \to \lambda\Sigma \f$ (see scale_Sigma)
99 - ladder correction, \f$ \Sigma_L \f$, if a ladder file was given
100 - large-r tail, \f$ a_{\rm eff}/r^4 \f$, beyond the sub-grid, if
101 tail_extrapolation is set (experimental; see fit_tail_coefficient)
102
103 Optionally also forms the energy derivative,
104 \f$ \partial\Sigma/\partial\varepsilon \f$ (see dSigmaFv).
105
106 @note Not thread safe: formSigma modifies internal state.
107*/
