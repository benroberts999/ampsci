MBPT::CorrelationPotential

ok

Correlation potential, Sigma, for valence states.

Core-valence correlations, stored as a non-local matrix for each kappa, on a radial sub-grid (every stride-th point of the full grid, between r0 and rmax). Formed at a given energy (see formSigma). Read from file if it exists, so it need only be formed once (see write).

Direct diagrams are formed using either the Goldstone (basis sum) or Feynman (Green's function) technique; the Feynman technique allows all-order inclusion of screening and the hole-particle interaction. Exchange diagrams always use Goldstone, with optional effective screening factors fk.

The action of Sigma on a state (SigmaFv) includes:

  • lambda scaling, \( \Sigma \to \lambda\Sigma \) (see scale_Sigma)
  • ladder correction, \( \Sigma_L \), if a ladder file was given
  • large-r tail, \( a_{\rm eff}/r^4 \), beyond the sub-grid, if tail_extrapolation is set (experimental; see fit_tail_coefficient)

Optionally also forms the energy derivative, \( \partial\Sigma/\partial\varepsilon \) (see dSigmaFv).

Note
Not thread safe: formSigma modifies internal state.

Reads Sigma from file if it exists; otherwise sets up to form it.

If fname exists, Sigma is read from it. Otherwise, sets up the Goldstone/Feynman method; Sigma itself is only formed by formSigma. The ladder file, if given, is read in either case.

Parameters

Forms and stores Sigma for given kappa, at energy ev.

If Sigma already exists for kappa and n (any n if n <= 0), it is not re-formed; only the tail fit and dSigma/dE are added if required and missing (e.g., Sigma read from file).

DiracSpinor MBPT::CorrelationPotential::dSigmaFv ( const DiracSpinor &  Fv) const

Returns lambda * dSigma/dE |Fv>.

\( \lambda \, (\partial\Sigma/\partial\varepsilon) \ket{F_v} \). The energy derivative of Sigma, formed by finite difference alongside Sigma itself (option form_derivative), so it corresponds to the actual method used (Goldstone/Feynman, screening, etc.). Scaled by the same lambda as the base Sigma.

Returns
lambda * dSigma/dE |Fv>; |0> if no derivative exists for this kappa.
Note
The ladder correction (Sigma_L) has no energy derivative: it is included in SigmaFv() but not here.

◆ average_fk()

std::vector< double > MBPT::CorrelationPotential::average_fk ( int  l_max = 2) const

Average of the stored fk screening factors, over l up to l_max.

Averaged over the lowest Sigma of each l. For re-use of the Sigma_1 screening in Sigma_2 (CI), where there is one effective fk per Coulomb line but no unique state: the low-l factors are the relevant ones for the CI valence space (higher-l factors can differ significantly, e.g., f/g at k = 0, but such states rarely contribute). Weighted by l, not kappa: the fine-structure pair of each l is averaged first, then the mean is taken over the ls (so s counts the same as p, d, ...). Truncated to the shortest stored list.

Parameters
l_maxMaximum l included in the average (CI uses 2: s, p, d).
Returns
Averaged fk, for each k; empty if none stored.
