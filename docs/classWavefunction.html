Wavefunction

ok

Stores Wavefunction (set of valence orbitals, grid, HF etc.)

Also holds the Hartree-Fock potential (and core), basis, spectrum, correlation potential (Sigma), and CI solutions.

Construction:
  • Set of GridParameters [see Maths/Grid]
  • Nuclear::Nucleus [see Potentials/NuclearPotentials]
  • var_alpha = \(\lambda\), \(\alpha = \lambda\alpha_0\)
  • run_label: Optional label for output identity - for distinguishing outputs with different parameters
Copying:
A copy has its own HF object (and core), but its Sigma (if formed) still refers to the HF object of the original (see copySigma). Applying Sigma does not use the HF object, but forming or writing Sigma does: these then use the original core (e.g., without any changes to the copy's HF), and the original must outlive the copy.

Returns energy location of the "Fermi Level".

◆ solve_valence()

void Wavefunction::solve_valence ( const std::string &  in_valence_str = "",
const bool  print = true 
)

Performs Hartree-Fock procedure for valence; populates valence.

Adds the states in in_valence_str (basis-string format, e.g., "7sp5d": up to n=7 for s and p, n=5 for d) that are not already in valence, and not in the core (except those after the ':' in the core string; see set_HF). Then solves for all valence states (existing ones are re-solved) in the HF potential, without Sigma, and copies them to hf_valence. If HF is not set, solves in the nuclear potential (H-like).

◆ solve_exotic()

void Wavefunction::solve_exotic ( const std::string &  in_exotic_str,
double  mass = PhysConst::m_muon,
bool  screening = true,
bool  print = true 
)

Solves for exotic atoms (e.g., muonic), including screening.

Resulting states are included in valence (flagged as exotic); the screening also updates core.

Each state is first solved in the nuclear (+QED) potential. With screening (and a non-empty core), the core HF equations are iterated including the direct potential of the first exotic state; the HF object (core) is then replaced by the screened one (Vnuc itself unchanged), and the exotic states are re-solved in the screened potential.

Note: The exotic states are just added to the valence list, so they can be used more simply with all the modules. However, be careful; for example, RPA will now be meaningless for these states!

Parameters
in_exotic_strStates, in basis-string format (e.g., "1s2p")
massMass of the exotic particle, in units of m_e
screeningInclude screening (core and exotic states)
printPrint energies and screening iterations
Note
With screening, any (electron) valence states already present are not re-solved, so are no longer consistent with the screened core.

◆ hartreeFockBrueckner()

void Wavefunction::hartreeFockBrueckner ( const bool  print = true)

Forms Brueckner valence orbitals; replaces existing valence states.

\( (H_{\rm HF} + \Sigma)\ket{nk} = \varepsilon\ket{nk} \). Does nothing if Sigma has not been formed; prints a warning and does nothing if HF is not set.

Note
Sigma is only formed for the HartreeFock method (see formSigma).

◆ fitSigma_hfBrueckner()

void Wavefunction::fitSigma_hfBrueckner ( const std::string &  valence_list,
const std::vector< double > &  fit_energies,
bool  separate_lambda = false 
)

First, fits Sigma to energies, then forms fitted Brueckner orbitals.

For each of the first fit_energies.size() valence states (in order), finds the scaling factor lambda such that the Brueckner energy, with lambda*Sigma, matches the given energy (damped iteration; lambda kept within [0.25, 2.5]). By default, fitted lambdas are averaged over each fine-structure pair (same n and l); separate_lambda = true keeps them separate. Then calls hartreeFockBrueckner.

Parameters
valence_listUnused
fit_energiesEnergies to fit to (au), in the same order as valence; sign ignored (binding energies)
separate_lambdaKeep lambdas of fine-structure pairs separate
Note
Each fitted state needs its own Sigma (same kappa and n; see each_valence in formSigma). Otherwise it is not fitted (lambda = 1 is printed): its energy is that with the lower-n Sigma.
Prints a warning and does nothing if Sigma has not been formed.

Forms + stores correlation potential Sigma.

Constructs Sigma (see MBPT::CorrelationPotential), reading it from file if it exists, and forms it for the valence states (see each_valence, ek). Then applies lambdas, optionally prints the energy shifts, and writes Sigma to file. Requires the basis (formBasis) for the Goldstone sums. Does nothing if the core is empty or HF is not set. Requires the HartreeFock method: prints a warning and does nothing otherwise.

Returns [min,max] r values for which the core density is > cutoff.

Core density for given l; cutoff = eps*max_value. Returns the r values (au) for which the value of \( \rho(r) = \sum|\psi|^2 \) drops below cutoff. Sum goes over all m for given l.
