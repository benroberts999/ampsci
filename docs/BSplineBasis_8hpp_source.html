19/*!
20 @brief Constructs spinor/orbital basis using B-splines
21
22 @details
23 Uses Bsplines to form a set of B-spline orbitals (using method from [1]
24 "Derevianko", [2] "Shabaev", [3] "Johnson", or [4] "Fischer", or the
25 "Hybrid" of [1] and [3]; see SplineType).
26 Diagonalises B-splines over Hamiltonian to produce a set of basis orbitals.
27
28 * [1] K. Beloy, A. Derevianko, Comput. Phys. Commun. 179, 310 (2008).
29 * [2] V. M. Shabaev, I. I. Tupitsyn, V. A. Yerokhin, G. Plunien, and G. Soff,
30 Phys. Rev. Lett. 93, 130405 (2004).
31 * [3] W. Johnson, S. Blundell, J. Sapirstein, Phys. Rev. A 37, 307 (1988).
32 * [4] C. F. Fischer and F. A. Parpia, Phys. Lett. A 179, 198 (1993).
33 * See also:
34 * Bachau et al., Reports Prog. Phys. 64, 1815 (2001).
35
36 By default, uses the Derevianko Dual Kinetic Balance (DKB) basis.
37
38 If \f$\{|i\rangle\}\f$ are the set of spline orbitals (of a given angular
39 symmetry; \f$2N\f$ of them, except Fischer with \f$\kappa>0\f$, see
40 spline_params), and
41 \f[
42 H_{ij} = \langle{S_i}|\hat H_{\rm HF}|{S_j}\rangle \,
43 , \qquad S_{ij} = \langle{S_i|S_j}\rangle.
44 \f]
45 The eigenvalue problem:
46 \f[
47 H_{ij}p_j = \epsilon S_{ij}p_j,
48 \f]
49 is solved, yielding one eigenvalue \f$\epsilon\f$ (with eigenvector
50 \f$p\f$) for each spline orbital: roughly half are positive-energy
51 solutions, and half negative-energy solutions.
52
53 Note: form_basis() does not store the eigenvectors, instead, it expands the
54 basis orbitals and stores them on the regular grid (coordinate space).
55 i.e., for each eigenvalue, n, the corresponding basis orbital is:
56 \f[
57 |{n}\rangle = \sum_i p_i |i\rangle\,
58 \f]
59*/
60namespace SplineBasis {

62/*!
63 @brief B-spline construction method (see details).
64
65 @details
66 - Derevianko (Reno): dual kinetic balance (DKB) splines; the first |kappa|
67 and the last spline are dropped, so the B-spline parts vanish at both
68 ends of the cavity (the kinetic-balance parts need not).
69 K. Beloy, A. Derevianko, Comput. Phys. Commun. 179, 310 (2008).
70 - Shabaev: DKB splines; the first and last spline are dropped, for all
71 kappa, with no boundary terms (as published: dropping more at r = 0 for
72 |kappa| >= 2 was found to make practically no difference).
73 V. M. Shabaev, I. I. Tupitsyn, V. A. Yerokhin, G. Plunien, and G. Soff,
74 Phys. Rev. Lett. 93, 130405 (2004).
75 - Johnson (Notre Dame): plain splines for f and g (no kinetic balance),
76 all kept; the boundary conditions f(0) = 0 and f(R) = -g(R) (MIT bag)
77 are imposed through boundary terms in the Hamiltonian matrix.
78 W. R. Johnson, S. A. Blundell, J. Sapirstein, Phys. Rev. A 37, 307
79 (1988).
80 - Fischer: plain splines (no kinetic balance); the first and
81 last spline are dropped (f = g = 0 at both ends), with no boundary
82 terms. For kappa > 0, the second spline is also dropped from f
83 (f'(0) = 0), which removes the spurious state found by Fischer and
84 Parpia for kappa = 1.
85 C. F. Fischer and F. A. Parpia, Phys. Lett. A 179, 198 (1993).
86 - Hybrid: DKB splines; the first |kappa| are dropped (as for
87 Derevianko), but the last is kept, and the Johnson rmax (MIT bag)
88 boundary term f(R) = -g(R) is imposed (see add_rmaxBoundary). Differs
89 from Derevianko only in the boundary condition at rmax.
90
91 See parseSplineType for the input strings.
92
93 @warning Fischer: bound states are accurate, but the pseudo-continuum
94 (cavity) states are not reliable: they disagree with those of the other
95 types, and for kappa > 0 some lie below the corresponding free-atom
96 energies. May not be suitable for MBPT; intended for testing only.
97*/
98enum class SplineType { Derevianko, Shabaev, Johnson, Fischer, Hybrid };
99
100//! Returns the canonical name string for a SplineType.
101inline std::string_view parseSplineType(SplineType type) {
102 switch (type) {
103 case SplineType::Johnson:
104 return "Johnson";
105 case SplineType::Fischer:
106 return "Fischer";
107 case SplineType::Hybrid:
108 return "Hybrid";
109 case SplineType::Shabaev:
110 return "Shabaev";
111 case SplineType::Derevianko:
112 return "Derevianko";
113 }
114 return "UnknownSplineType";
115}

117/*!
118 @brief Parses a string to SplineType (case-insensitive).
119
120 @details
121 - Derevianko (default; aliases: reno, dkb)
122 - Shabaev
123 - Johnson (aliases: nd, notredame, notre-dame)
124 - Fischer
125 - Hybrid
126
127 See SplineType for a description of each.
128
129 @return The SplineType; Derevianko if @p type is empty.
130
131 @warning An unrecognised @p type prints a warning and returns Derevianko.
132*/
133inline auto parseSplineType(std::string_view type) {
134 using qip::ci_compare;
135 if (ci_compare(type, "Johnson") || ci_compare(type, "nd") ||
136 ci_compare(type, "NotreDame") || ci_compare(type, "Notre-Dame"))
137 return SplineType::Johnson;
138 if (ci_compare(type, "Fischer"))
139 return SplineType::Fischer;
140 if (ci_compare(type, "Hybrid"))
141 return SplineType::Hybrid;
142 if (ci_compare(type, "Shabaev"))
143 return SplineType::Shabaev;
144 if (ci_compare(type, "Derevianko") || ci_compare(type, "Reno") ||
145 ci_compare(type, "DKB") || type.empty())
146 return SplineType::Derevianko;
147 std::cout << "Warning: unknown SplineType '" << type
148 << "'. Defaulting to Derevianko.\n";
149 return SplineType::Derevianko;
150}

152/*!
153 @brief Default first internal knot, r0, for each l, for the given type.
154
155 @details
156 Element l is the first knot for orbital angular momentum l; the last
157 element is used for all higher l (see form_basis).
158 - Dual-kinetic-balance types (Derevianko, Shabaev, Hybrid): 1e-4 for all l
159 - Types without kinetic balance (Johnson, Fischer): 3e-4 for s, 1e-4 for
160 p, 1e-3 for d and f, 1e-2 for higher l. As in Johnson et al. (Table
161 III), the first knot is moved out for higher l, since these orbitals are
162 negligible close to the nucleus, which improves the knot distribution.
163 The s and p values give the most accurate hyperfine constants and
164 Drake-Goldman sum rules for Cs (see the basis tests); in particular, a
165 first s knot at 1e-4 degrades the s-state hyperfine constants.
166*/
167std::vector<double> default_r0(SplineType type);

207/*!
208 @brief Forms and returns the basis orbitals (expanded in terms of splines).
209
210 @details
211 Members of @p params:
212 - states = which states to keep e.g., "25spd10f" (up to n=25 for
213 s,p,d-states, and up to n=10 for f states)
214 - n: Number of splines (the underlying spline set may be larger; see
215 spline_params)
216 - k: k order of the B-splines. NB: must have \f$k\geq l_{\rm max}+3\f$ [1]
217 - r0: first internal knot, for each l: r0[l] is used for orbital angular
218 momentum l, and the last entry for all higher l (so a single value
219 applies to all l). Empty: default_r0(type). Values below the first grid
220 point are replaced by it.
221 - rmax: last knot (basis orbitals only non-zero before this point)
222 - positron: basis string giving the number of negative-energy states to
223 keep for each kappa (e.g., "9spdf" keeps 9 of each). Those closest to
224 -2mc^2 are kept. They are labelled with n continuing on from the
225 positive-energy solutions (so {n,kappa} stays unique), are flagged
226 (DiracSpinor::negativeEnergyStateQ), and are appended to the end of the
227 basis std::vector. Empty string discards them. Must be a subset of states.
228 A warning is also printed if any label is too large for DiracSpinor::nk_index (n > 256;
229 e.g., many splines with many negative-energy states kept).
230 - type: B-spline construction method (see SplineType)
231 - verbose: print construction details to screen
232 - orthogonalise: not used here (see Wavefunction::formBasis)
233
234 @param params Basis parameters (see above)
235 @param wf Wavefunction object: needed to form Hartree-Fock
236 Hamiltonian
237 @param correlationsQ If true, includes the correlation potential (Sigma)
238 of @p wf in the Hamiltonian (if it exists)
239
240 @return Basis orbitals: electron states for each kappa (in the order of
241 @p params.states, increasing n), followed by any negative-energy
242 states.
243
244 @note This function calls the below functions, they rarely need to be
245 called explicitly, unless you are trying to do something different
246 to usual.
247*/
248std::vector<DiracSpinor> form_basis(const Parameters &params,
249 const Wavefunction &wf,
250 const bool correlationsQ = false);

343/*!
344 @brief Forms the underlying spline basis (which is not kept).
345
346 @details
347 Forms the spline spinors for given kappa from the B-splines \f$B_i\f$
348 selected by spline_params: \f$N_f\f$ "f-like" followed by \f$N_g\f$
349 "g-like" (both equal to @p n_states, except Fischer with kappa > 0),
350 \f[
351 S_i = \begin{pmatrix} B_i \\
352 \frac{\lambda\alpha}{2}\left(B_i' + \frac{\kappa}{r}B_i\right)
353 \end{pmatrix},
354 \qquad
355 S_{N_f+i} = \begin{pmatrix}
356 \frac{\lambda\alpha}{2}\left(B_i' - \frac{\kappa}{r}B_i\right) \\ B_i
357 \end{pmatrix},
358 \f]
359 where \f$\lambda\f$ is the kinetic balance prefactor (SplineParams). Knots
360 are distributed log-linearly between @p r0_spl and @p rmax_spl, with the
361 end points (0 and rmax) repeated k times: only the first spline is
362 non-zero at r = 0, and only the last at r = rmax.
363
364 @param kappa Dirac quantum number
365 @param n_states Number of splines, N, of each type (f-like and g-like;
366 N-1 f-like for Fischer with kappa > 0)
367 @param k_spl Order of the B-splines
368 @param r0_spl First internal knot
369 @param rmax_spl Last knot (splines are zero beyond this point)
370 @param rgrid Radial grid the splines are stored on
371 @param alpha Fine-structure constant
372 @param itype B-spline construction method
373
374 @return The N_f + N_g spline spinors, their radial derivatives (d/dr of
375 both f and g), and the values of f and g of each exactly at rmax
376 (which is generally between grid points).
377*/
378SplineSpinors form_spline_basis(const int kappa, const std::size_t n_states,
379 const std::size_t k_spl, const double r0_spl,
380 const double rmax_spl,
381 std::shared_ptr<const Grid> rgrid,
382 const double alpha,
383 SplineType itype = SplineType::Derevianko);

385/*!
386 @brief Calculates and returns the Hamiltonian matrix H_ij and overlap S_ij.

409/*!
410 @brief Applies Johnson/Notre-Dame boundary conditions to Hamiltonian matrix.
411
412 @details
413 Adds the boundary term of the action, S' [Eq. (10) of Johnson et al.],
414 together with the surface term \f$\frac{c}{2}[fg]_0^R\f$ by which the
415 symmetric kinetic matrix (Wavefunction::H0ab) differs from the
416 antisymmetrised form of Johnson et al. [Eq. (7)], so that f(0) = 0 and
417 f(R) = -g(R) [MIT bag, P(R) = Q(R); g = -Q here] become the natural
418 boundary conditions. Only the first spline is non-zero at r = 0
419 (B_1(0) = 1), and f(R), g(R) are those of the spline spinors at rmax (see
420 add_rmaxBoundary):
421 \f[
422 S' + \frac{c}{2}[fg]_0^R =
423 \frac{c}{2} f(0)^2 \ [\kappa<0] \ {\rm or}\ c^2 f(0)^2 \ [\kappa>0]
424 + \frac{c}{4}\left[f(R)^2 - g(R)^2\right] + \frac{c}{2} f(R) g(R),
425 \f]
426 (the f(0)g(0) terms cancel). The matrix gets its second derivatives. The
427 cancellation is exact analytically; on the radial grid it holds only to the
428 accuracy of the quadrature at the cavity ends.
429 W. R. Johnson, S. A. Blundell, J. Sapirstein, Phys. Rev. A 37, 307 (1988).
430
431 @param Aij Hamiltonian matrix, 2N x 2N (N f-like splines, then N
432 g-like); updated in place
433 @param kappa Dirac quantum number
434 @param alpha Fine-structure constant
435 @param f_rmax f(rmax) of each spline spinor (see SplineSpinors)
436 @param g_rmax g(rmax) of each spline spinor
437*/
438void add_JohnsonBoundary(LinAlg::Matrix<double> *Aij, const int kappa,
439 const double alpha, const std::vector<double> &f_rmax,
440 const std::vector<double> &g_rmax);
441
442/*!
443 @brief Applies the rmax (MIT bag) boundary term only: f(R) = -g(R).
444
445 @details
446 The r = R part of add_JohnsonBoundary (no r = 0 term); also used alone for
447 the Hybrid type. With \f$f(R) = \sum_i p_i u_i\f$ and
448 \f$g(R) = \sum_i p_i w_i\f$, where \f$u_i\f$, \f$w_i\f$ are f and g of
449 spline spinor i at R, adds the second derivatives of
450 \f[
451 \frac{c}{4}\left[f(R)^2 - g(R)^2\right] + \frac{c}{2} f(R) g(R):
452 \quad
453 \frac{c}{2}\left(u_iu_j - w_iw_j + u_iw_j + w_iu_j\right).
454 \f]
455 Without kinetic balance (Johnson), only the last f-like (u = 1) and last
456 g-like (w = 1) spinors are non-zero at R. With kinetic balance (Hybrid),
457 the kinetic-balance parts of the last two splines of each set also
458 contribute, so these are included.
459
460 @param Aij Hamiltonian matrix (f-like spinors, then g-like); updated in
461 place
462 @param alpha Fine-structure constant
463 @param f_rmax f(rmax) of each spline spinor (see SplineSpinors)
464 @param g_rmax g(rmax) of each spline spinor
465*/
466void add_rmaxBoundary(LinAlg::Matrix<double> *Aij, const double alpha,
467 const std::vector<double> &f_rmax,
468 const std::vector<double> &g_rmax);

505/*!
506 @brief TKR sum rule (basis test); should be zero (needs -ve energy states).
507
508 @details
509 Thomas-Kuhn-Reiche sum rule. With a the first state in @p basis, for each
510 l up to the maximum l in @p basis:
511 \f[
512 \sum_n \frac{w_n}{2l+1} (\varepsilon_n - \varepsilon_a)
513 \langle a|r|n\rangle^2 = 0,
514 \f]

516 \f$\kappa_n = -l-1\f$ (\f$w_n = l+1\f$), where
517 \f$\langle a|r|n\rangle\f$ is the radial integral.
518
519 @param basis Basis orbitals (including negative-energy states)
520 @param r Radial grid points
521 @param print Print electron and negative-energy contributions, for each l
522
523 @return The sum, for each l; empty if @p basis is empty.
524*/
525std::vector<double> sumrule_TKR(const std::vector<DiracSpinor> &basis,
526 const std::vector<double> &r,
527 bool print = false);

529/*!
530 @brief Drake-Goldman sum rules (basis test); should be zero.
531
532 @details
533 Must include negative-energy states in @p basis.
534 For each kappa in @p basis (a: the first basis state with that kappa):
535 \f[
536 \frac{1}{2j_a+1}\sum_n (\varepsilon_n - \varepsilon_a)^{m}
537 |\langle a||r||n\rangle|^2
538 \f]
539 where m = @p nDG, compared with its exact value:
540 \f$\langle a|r^2|a\rangle\f$ (m=0) or 0 (m=1). For m=2, the sum is scaled
541 by \f$\alpha^2/3\f$, and compared with 1. Kappas with l equal to the
542 maximum l in @p basis are skipped (no l+1 states to sum over).
543
544 @param nDG Power of the energy difference, m: 0, 1, or 2
545 @param basis Basis orbitals (including negative-energy states)
546 @param gr Radial grid
547 @param alpha Fine-structure constant
548 @param print Print sum, exact value, and difference, for each kappa
549
