Amplitudes::SRNdata

ok

Result of a matrix element calculation with second-order MBPT corrections: structure radiation, normalisation, Brueckner orbital.

Everything is stored unscaled; the accessors apply the MatrixElementType factor. The total corrected matrix element is

\[ t^{\rm tot}_{ab} = t^{(0)}_{ab} + \delta V_{ab} + \delta t^{\rm SR}_{ab} + \delta t^{\rm Norm}_{ab} + \delta t^{\rm BO}_{ab}. \]
