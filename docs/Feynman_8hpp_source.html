70/*!
71 @brief Direct correlation potential diagrams via the Feynman technique.
72
73 @details
74 Constructs Hartree-Fock Green's functions, the polarisation operator, and
75 the direct Sigma diagrams, as matrices on a radial sub-grid. The direct
76 Sigma is formed by integrating, along Im(w) at fixed Re(w) = omre, the
77 product of the Green's function \f$ G(\varepsilon_v + \omega) \f$ and the
78 Coulomb-polarisation-Coulomb operator, \f$ Q\Pi Q(\omega) \f$.
79
80 Allows all-order inclusion of:
81 - screening of the Coulomb interaction:
82 \f$ Q\Pi Q \to Q\Pi X Q \f$, with \f$ X = [1 + iQ\Pi]^{-1} \f$
83 - the hole-particle interaction, in the polarisation operator
84
85 Exchange diagrams are not formed here (see Goldstone).
86*/

456/*!
457 @brief Best real part of the frequency, omre, for the direct diagram.
458
459 @details
460 The value furthest from any pole of the u=0 integrand. With
461 \f$ \Delta = \varepsilon_{\rm exc} - \varepsilon_{\rm core} \f$
462 (lowest excited minus highest core energy), the window
463 \f$ (-\Delta, 0) \f$ is free of true poles; inside it lie only the weak
464 fictitious poles at core-core energy differences (imperfect core
465 subtraction in the polarisation-loop Gex) and, for non-lowest valence
466 states, the small valence-valence differences (valence-line G). Only the
467 lowest few physical excited states enter, so the valence list suffices: no
468 basis/spectrum needed (a typical valence energy is assumed if the list is
469 empty). One omre serves all valence states.
470
471 @param core Core states
472 @param valence Valence states (lowest sets the window)
473 @param print Print Delta, the in-window poles, and the chosen omre
474
475 @return Midpoint of the largest pole-free gap.
476*/
477double best_omre(const std::vector<DiracSpinor> &core,
478 const std::vector<DiracSpinor> &valence, bool print = false);
