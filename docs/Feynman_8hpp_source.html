292//! Best real part of the frequency, omre, for the direct diagram: the value
293//! furthest from any pole of the u=0 integrand.
294//! @details With Delta = e_lowest_excited - e_core_max, the window
295//! (-Delta, 0) is free of true poles; inside it lie only the weak fictitious
296//! poles at core-core energy differences (imperfect core subtraction in the
297//! polarisation-loop Gex) and, for non-lowest valence states, the small
298//! valence-valence differences (valence-line G). Only the lowest few
299//! physical excited states enter, so the valence list suffices: no
300//! basis/spectrum needed (a typical valence energy is assumed if the list is
301//! empty). Returns the midpoint of the largest pole-free gap; one omre
302//! serves all valence states. Set print=true to show Delta, the in-window
303//! poles, and the chosen omre.
304double best_omre(const std::vector<DiracSpinor> &core,
305 const std::vector<DiracSpinor> &valence, bool print = false);
