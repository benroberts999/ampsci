Green parametric potential at r; electron part only (no nuclear).

\[ V(r) = \frac{Z}{r} - \frac{1}{r} \left[ 1 + \frac{Z-1}{H\,(e^{r/d} - 1) + 1} \right]. \]

The total potential is V(r) - Z/r. Returns 0 at r = 0, and for Z = 1 (no screening electrons).

Tietz parametric potential at r; electron part only (no nuclear).

\[ V(r) = \frac{Z}{r} - \frac{1}{r} \left[ 1 + \frac{(Z-1)\,e^{-g r}}{(1 + t r)^2} \right]. \]

The total potential is V(r) - Z/r. Returns 0 at r = 0.

Default Green parameters H and d for given Z, tuned to match HF core.

Tabulated for selected Z, linearly interpolated in between. For Z > 113, H = 5.0, d = 0.75.

Returns
Always 0; H and d are set by reference.
Note
For Z = 1, H = d = 0: unused, since there is no screening.
