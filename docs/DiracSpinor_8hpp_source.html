10/*!
11 @brief Stores radial Dirac spinor: F_nk = (f, g)
12
13 @details
14 \f[
15 \psi_{n\kappa m} = \frac{1}{r}
16 \begin{pmatrix}
17 f_{n\kappa}(r)\,\Omega_{\kappa m}\\
18 g_{n\kappa}(r)\,\Omega_{-\kappa m}
19 \end{pmatrix},
20 \quad
21 F_{n\kappa} =
22 \begin{pmatrix}
23 f_{n\kappa}(r)\\
24 g_{n\kappa}(r)
25 \end{pmatrix}
26 \f]
27
28 \par Construction.
29 Takes in constant n and k=kappa values + grid
30 - A shared pointer to the Grid is stored (to avoid many copies of Grid)
31
32 \par Operator Overloads
33 - Intuative operator overloads are provided (Fa, Fb are DiracSpinors):
34 - v * Fa, where v is a double or vector works the obvious way
35 - Fa * Fb = <Fa|Fb>
36 - Fa == Fb returns true if {na,ka}=={nb,kb}
37 - Fa > Fb : first compares n, and then kappa (via kappa_index)
38 - Fa +/- Fb : Adds/subtracts the two spinors (and updates p0/pinf)
39 - You can make copies: auto Fnew = Fa
40 - And you can re-asign: Fb = Fa (provided Fa and Fb have same n and kappa!)
41 - n and kappa are constant, cannot be changed. Avoids angular errors.
42 - all 'set_' functions return mutable references to variables
43*/
