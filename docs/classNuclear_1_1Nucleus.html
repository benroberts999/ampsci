Constructs nucleus from Z and A, with optional parameters.

r_rms is taken from isotope data if not given; if not in the isotope data, an approximate formula is used. A = 0 gives r_rms = 0 (point-like), regardless of in_rrms. For non-Fermi types, t is set to zero.

Parameters
in_zNuclear charge, Z
in_aMass number, A. Negative: default A for Z; 0: point-like
str_typeCharge distribution type (see parseType)
in_rrmsRoot-mean-square charge radius (fm). Negative: from isotope data
in_tSkin thickness (fm), Fermi only. Negative: default_t
in_betaQuadrupole deformation parameter (Fermi only)
in_paramsExtra parameters (not currently used)
custom_pot_file_nameFile for custom nuclear potential
