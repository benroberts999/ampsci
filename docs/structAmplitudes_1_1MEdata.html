Amplitudes::MEdata

ok

Result of a single matrix element calculation.

Holds \( \redmatel{a}{h}{b} \): the lowest-order value, the RPA (core polarisation) correction, the transition frequency, and the factor that converts the reduced matrix element to the requested form (reduced, stretched, or hyperfine constant); see DiracOperator::MatrixElementType.

Everything is stored unscaled; value() and value0() apply the factor.
